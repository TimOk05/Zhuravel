# Studio Zhuravel — website concept

A responsive, buildless landing page for a South Coast mobile valeting business.

## Local development

```bash
npm install
npx playwright install chromium
npm run dev
```

Open `http://127.0.0.1:4177`.

## Validation

```bash
npm test
```

The Playwright suite checks the layout at mobile, tablet and desktop widths, key interactions, image loading and browser errors.

## Content notes

The business name, Instagram account and South Coast positioning are based on the public Instagram profile. Prices, specific coverage areas and unverified business claims are intentionally omitted until the business confirms them.
